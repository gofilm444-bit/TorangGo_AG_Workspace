# Product Documentation

TorangGo is a provisional working brand for a local commerce and on-demand delivery platform.

## Current Direction (Phase 1)
- Local Commerce / Food
- On-Demand Delivery
- Single Outlet UX / Single Merchant Profile

## Future Potential (Not In Scope)
- Mart
- Courier
- Ride
- Pharmacy Delivery
- On-Demand Home Services
- Franchise hierarchies
